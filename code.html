GMM with Common Correlated Effects
Replication code for GMM estimators of short dynamic panel data models with unobserved common factors and latent-group slope heterogeneity — AB-GMM, IFE and CCE variants, Monte Carlo simulations, and an empirical application to seven World Bank development indicators (1990–2019).

GMM with Latent Group Structure
Replication package for a bias-corrected method of moments estimator for dynamic panel data models with a short time dimension and latent group structure in the slope coefficients — Monte Carlo simulations plus empirical applications to cross-country savings rates and the income–democracy relationship.

View on GitHub
Three-Dimensional Panel with CCE Framework
Replication code for a common correlated effects estimator for dynamic three-dimensional (origin–destination–time) heterogeneous panel data, augmenting each unit-pair regression with cross-sectional averages to absorb global, origin- and destination-specific shocks — Monte Carlo study and an empirical application to bilateral export flows (18 origins × 19 destinations, 1995–2024).
